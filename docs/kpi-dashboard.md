# AI and Cybersecurity News KPI Dashboard Spec

Track weekly, review every 7 days, and update actions in backlog.

## Core KPIs

| KPI | Formula | Target range | Alert threshold |
|---|---|---|---|
| Weekly sessions | Analytics sessions | 1,500 - 3,000 | < 1,000 |
| Affiliate CTR | affiliate_click / sessions to money pages | 5% - 9% | < 3.5% |
| Affiliate conversion rate | affiliate conversions / affiliate clicks | 6% - 10% | < 4% |
| Newsletter opt-in rate | newsletter_submit_success / sessions | 3% - 6% | < 2% |
| Product page CTR | product page visits / total sessions | 5% - 10% | < 3% |
| Product conversion rate | purchases / product page visits | 3% - 7% | < 2% |
| Revenue per 100 visitors | total revenue / sessions * 100 | $10 - $18 | < $6 |

## Event mapping

Use these tracked events:

- `lead_magnet_click`
- `newsletter_submit_success`
- `affiliate_click`
- `product_checkout_click`
- `auth_login_attempt`
- `auth_register_attempt`

## Weekly review template

1. Traffic: Which pages grew/declined?
2. CTR: Which CTA blocks underperformed?
3. Offer: Which tool/product links had highest conversion intent?
4. Content: Which cluster (AI, CS, Tools) needs more publishing?
5. Action list: Top 3 edits for next week.

## Leading indicators for $1,000/month

- 8k+ monthly sessions with buyer-intent distribution
- 5%+ affiliate CTR on money pages
- 3%+ opt-in rate
- 3%+ product conversion on product page visits
- >= $10 revenue per 100 sessions

## Suggested dashboard layout

- Acquisition: sessions, top landing pages, EN/FR split
- Engagement: scroll depth, CTA clicks by block
- Monetization: affiliate clicks, product checkout clicks, estimated revenue
- Email: opt-ins by source, sequence open/click rates, sales attribution
